# Pool Vision v1.0 (starter project)

A simple Android manual training overlay. It draws a cue-to-target guideline and a projected continuation line.
It does not capture the screen, detect balls, automate taps, or modify 8 Ball Pool.

## Build on GitHub from an Android phone
1. Create a new empty GitHub repository named `PoolVision`.
2. Upload the contents of this folder (not the outer folder) to the repository.
3. Open the **Actions** tab and run **Build Pool Vision APK** (or push to `main`).
4. Open the completed workflow run and download the `PoolVision-debug-apk` artifact.
5. Extract the artifact ZIP and install `app-debug.apk`.
6. On first launch, grant **Display over other apps**, then tap **Start training overlay**.

The overlay is manually positioned. It is a prototype, not a calibrated physics engine. Keep it for offline/practice use and follow the game's rules.
